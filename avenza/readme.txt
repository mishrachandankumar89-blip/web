Custom WordPress theme for AVENZA: lush emerald and white design, native block content, one-click setup, schema, llms.txt and AI crawler rules.

== Description ==

AVENZA is a classic WordPress theme with full block editor support, built for a digital marketing agency that sells Generative Engine Optimization, Answer Engine Optimization, SEO, content, digital PR, Google Ads, social media, websites and conversion work.

What it includes:

* One-click setup (Appearance > AVENZA Setup) that builds 9 pages, 12 service pages, 6 articles, 26 images, the menus, the front page and the Insights page.
* Version updates that refresh theme pages but keep any page you have edited yourself.
* Every page built from core blocks, so everything is edited in the normal WordPress editor with no page builder.
* Services post type at /services/<name>/, and an Enquiries post type that stores every contact form submission.
* Contact form with nonce, honeypot, time trap, rate limiting and server-side validation, plus DPDP-style consent.
* Meta titles and descriptions, canonical tags, Open Graph and Twitter cards. These switch off automatically if Yoast SEO, Rank Math, AIOSEO or SEOPress is active.
* JSON-LD for Organization, WebSite, WebPage, BreadcrumbList, Service, ItemList, FAQPage and BlogPosting.
* llms.txt served at /llms.txt and a robots.txt that welcomes search and AI crawlers.
* Sticky header, accessible dropdown, focus-trapped mobile menu, WhatsApp and call buttons, back to top.
* Self-hosted fonts, no jQuery, deferred JavaScript, lazy-loaded images, WCAG AA contrast.

== Installation ==

1. Appearance > Themes > Add New > Upload Theme, choose avenza.zip, then Install and Activate.
2. Click "Set up the AVENZA website" in the notice, or open Appearance > AVENZA Setup.
3. Open Appearance > Customize > AVENZA Settings to add your email, address, social profiles and GA4 ID.

== Frequently Asked Questions ==

= Where do contact form enquiries go? =

To the email in Customize > AVENZA Settings > Contact Details (or the site admin email), and they are always saved under Enquiries in the dashboard.

= Can I use an SEO plugin? =

Yes. The theme's own meta tags step aside when Yoast SEO, Rank Math, AIOSEO or SEOPress is active.
